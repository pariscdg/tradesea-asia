# TradeSea Asia

[Download the latest release](https://github.com/pariscdg/tradesea-asia/releases/latest)

1. Install Google Chrome.
2. Download **TradeSeaAsia.exe**, put it in a permanent folder, and open it.
3. Click **Sign in** and log into TradeSea.
4. Drag accounts into **Asia** or **24-hour**. Choose 6, 8, or 12 hours for Asia in Settings.
5. Click **Save changes** and wait for the scheduling confirmation.

Runs Sunday-Thursday at **5 PM Windows local time**. The task requests waking the PC from sleep; Windows wake timers must be allowed. Stay signed into Windows. You can close the app.
